# 초심자 사용성 시험 · 기존 OTA를 바탕으로 새 설계 만들기

## 참가자에게 드리는 과제

IC Studio의 아날로그 예제에는 `ota5t`라는 증폭기(OTA)가 있습니다. 이 설계를 바탕으로 별도 셀 `ota5t_gbw2x`를 만들어 주세요. 기준 조건에서 새 셀의 속도 지표가 원본의 2배 이상이면 목표를 달성한 것입니다. 원본 회로는 그대로 두고, 끝나면 원본과 새 셀이 모두 들어 있는 프로젝트를 저장해 주세요.

이 과제에서 속도 지표는 **단위 이득 주파수**입니다. 화면에서 `UNITY GAIN f` 또는 `ugf`로 표시됩니다. 원본의 실제 측정값에 2를 곱해 목표를 정하고, 원본과 새 셀은 같은 시뮬레이션 조건에서 비교해 주세요. 기존 이득과 위상 여유 목표도 유지해 주세요.

시작 화면에서 진행자가 알려 준 시험용 프로젝트를 열어 주세요. 화면이나 내장 도움말에서 필요한 정보를 찾아도 됩니다. 무엇을 찾고 있는지, 다음에 어떤 일이 일어날 것으로 예상하는지 소리 내어 말해 주세요. 막히거나 목표를 달성하지 못한 경우, 어디까지 했고 화면에 무엇이 나왔는지 그대로 남겨 주세요.
