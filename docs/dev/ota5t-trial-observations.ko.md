# 초심자 사용성 시험 · 진행 및 관찰 기록지

[참가자용 과제](ota5t-trial-task.ko.md)만 먼저 전달합니다. IC 회로 설계 경험이 거의 없고 이 기능을 처음 써 보는 사람을 우선 모집합니다. 일반적인 CAD나 시뮬레이터 경험은 배경 정보로 적습니다.

## 사전 준비

- **새 설계 파생** 기능이 포함된 빌드를 준비합니다. 저장소에서 앱을 실행하려면 `cargo run -p ics-studio --bin ic-studio`를 사용합니다. 참가자마다 새 시험용 폴더를 쓰고, 앱 시작 화면과 초심자 모드에서 시작합니다.
- 시작 화면의 **예제 > 아날로그**에서 `work/ota5t`를 엽니다. 시뮬레이션 워크스페이스에서 **내장 엔진**과 기본 모델을 사용하고, AC의 **Stop freq**를 `10g`에서 `30g`로 변경합니다. `10g`는 이번 사전 점검에서 2배 목표보다 낮았습니다. 회로와 부하 조건은 예제 그대로 두고 `Ctrl+S`로 시험용 프로젝트를 저장합니다. 참가자에게는 폴더 위치만 알려 주세요.
- 준비한 프로젝트의 별도 복사본에서 `v(out)`의 `UNITY GAIN f`를 읽고, 원본 실측값의 2배를 `ugf` 하한으로 설정해 파생을 실행합니다. 사용하는 빌드에서 측정값과 목표 달성 가능 여부를 기록합니다. 이 과제의 전후 비교는 같은 조건에서 나온 단일 AC 측정값으로 합니다.
- 시험 중 목표를 놓치거나 측정값이 비어 있으면 그때의 설정과 화면을 먼저 기록합니다. 새 셀 생성, 결과 해석, 저장까지 어디까지 진행했는지 이어서 관찰합니다.

사전 점검에서 소스 빌드 `0.2.12`의 CLI와 내장 엔진으로 AC 범위 `1k`–`30g`를 사용했습니다. 27 °C에서 UGF는 **5.43 GHz → 11.40 GHz**였고, 새 셀은 세 온도에서 이득·UGF·위상 여유 목표를 통과했습니다. DRC와 LVS도 통과했고, 결과에 전류 미러의 게이트 면적 감소가 표시됐습니다. 이 수치는 진행자 참고용입니다.

## 진행 및 기록

안내 2분, 과제 25분, 마무리 질문 5분을 기준으로 진행합니다. 참가자가 멈추면 먼저 “지금 무엇을 찾고 있나요?”라고 묻습니다. 약 2분 동안 진전이 없거나 참가자가 도움을 요청하면 아래 힌트를 하나씩 줍니다. 관찰에는 첫 클릭, 예상, 실제 화면, 멈춘 시간, 준 힌트와 그 뒤의 행동을 남깁니다. 화면에 나온 문구는 가능한 한 그대로 적습니다.

| 관찰 지점 | 경과 시간 | 참가자의 행동과 말 | 실제 화면·오류와 막힌 시간 | 도움과 이후 결과 |
| --- | --- | --- | --- | --- |
| 시작 화면에서 원본 프로젝트와 셀 찾기 | | | | |

### 진행자용 힌트

1. **파일 > 프로젝트 열기…**에서 받은 시험용 폴더를 열고 탐색기에서 `ota5t` 회로도를 찾아보세요.
2. `F5`로 실행하고 **AC** 탭의 측정 표에서 `v(out)`의 **UNITY GAIN f**를 찾아보세요. 행이 보이지 않으면 신호 목록에서 `v(out)`을 선택하세요.
3. 회로도로 돌아와 빈 곳을 클릭하고 오른쪽 패널의 **이 설계에서 새 설계 파생…**을 찾아보세요. 마법사의 `ugf` 목표 하한을 원본 실측의 2배로 바꿔 보세요. 예를 들어 4.2 GHz를 읽었다면 `8.4g`입니다. `gain_db`와 `pm`은 기존 값을 유지하고 나머지 옵션은 기본값으로 시작하세요.
4. **만들고 크기 정하기**를 누른 뒤 전후 값과 통과 여부를 보세요. 새 셀에서도 `F5`를 실행해 같은 조건에서 비교할 수 있습니다. `—`가 보이면 빈 측정값으로 기록하세요. AC 범위 안에 0 dB 교차점이 있는지 진행자가 따로 확인합니다.
5. `Ctrl+S`로 시험용 폴더에 저장하고, 다시 열어 원본과 새 셀이 보이는지 확인하세요.

## Windows 수동 확인

본 과제 관찰이 끝난 뒤 별도 시험용 복사본에서 진행합니다. 각 행에 `통과`, `실패`, `미실행`과 실제 메시지 또는 화면 위치를 남깁니다. 장비나 다운로드 빌드가 없으면 사유를 적습니다. 기존 항목은 [Windows 검증 보고서](windows-report.md#needs-a-human)에 있습니다.

| 항목 | 절차와 관찰할 동작 | 결과 / 재현 정보 |
| --- | --- | --- |
| 한글 IME | `Win+Space`로 한국어 IME를 선택하고 `Ctrl+K` 검색창에서 한글을 조합, 확정, 취소합니다. 레이아웃을 열고 명령 팔레트에서 **Process Emulation**을 찾아 **Edit flow > TOML**에서도 반복합니다. 시험용 TOML에 한글 주석을 저장하고 다시 엽니다. 새 셀 이름 입력란에서도 조합이 정상인지, 한글 이름 제출 시 허용되는 이름 규칙이 이해하기 쉽게 표시되는지 확인합니다. | |
| HiDPI | Windows 화면 배율을 각각 150%, 200%로 맞추고 회로도, 레이아웃, 파생 창을 엽니다. 텍스트, 메뉴, 하단 버튼의 잘림이나 클릭 위치 어긋남을 확인합니다. 배율이 다른 모니터가 있으면 창을 옮긴 뒤 반복합니다. | |
| 클립보드 | 메모장과 IC Studio의 입력란 사이에서 `Ctrl+C` / `Ctrl+V`를 양방향으로 실행합니다. 한글과 영문이 그대로 복사되는지, Windows 메뉴에 `Ctrl` 단축키가 표시되는지 확인합니다. | |
| GDS 드래그 앤 드롭 | 시험용 셀을 GDS로 내보낸 뒤 탐색기에서 그 파일을 앱 창으로 끌어다 놓습니다. 가져오기 창이 열리는지와 무반응 또는 오류 여부를 기록합니다. | |
| SmartScreen | 승인된 배포 경로에서 받은 서명 없는 Windows 빌드를 탐색기에서 실행합니다. 파일명과 버전, 경고 표시 여부, 표시 문구를 기록합니다. 조직 정책으로 실행이 차단되면 그 상태까지 기록합니다. | |

## 외부 넷리스트에서 막힌 경우

이 과제는 내장 예제로 진행합니다. 별도 외부 덱에서 오류가 나면 사용한 백엔드와 오류 원문을 기록합니다. 내장 엔진은 무손실 전송선 `T`, 레벨 1 JFET `J`, 종속 소스 `POLY` 및 `VALUE`를 지원합니다. JFET 레벨 2나 `TABLE`이 필요한 경우 ngspice가 설치된 환경에서 **Auto** 또는 **ngspice**로 전환해 결과를 확인합니다. [시뮬레이션 백엔드](../ko/simulation.md#백엔드)

## 첫 참가자 기록 · 2026-11-23

- 참가자 P01은 IC 설계 경험이 없다고 답했습니다. 빌드 0.2.12의 별도 설정에서 시작 화면을 열었습니다.
- 과제 설명만 전달받은 뒤 무엇을 해야 할지 모르겠다고 보고했고, 단계별 안내를 요청했습니다. 프로젝트 열기부터 원본 측정, 목표 입력, 파생 결과 확인과 저장까지 안내했습니다.
- 목표를 계산하는 단계에서 입력란의 위치를 다시 물었습니다. 다음 단계에서 파생 창을 열면 **Targets > ugf > Min**에 기존 값 `100meg`가 보인다고 안내했습니다. 진행 안내에서는 계산과 입력 순서를 붙여 설명하는 편이 명확합니다.
- 참가자는 파생을 마친 뒤 영어 화면의 항목을 찾는 데 어려움이 있었을 가능성을 이야기했습니다. 파생은 **힌트 후 완료**로 기록했습니다. 생성된 셀은 저장 전 상태였고, 확인 뒤 앱의 라이브 API로 저장을 보조했습니다. 참가자가 직접 저장하는 단계는 완료에 이르지 못했습니다.
- 저장된 `ota5t_gbw2x`의 UGF는 27 °C에서 11.402 GHz였습니다. 원본은 5.430 GHz였고, 회로도 해시가 기준과 일치했습니다. 새 셀은 목표 10.86 GHz와 세 온도의 스펙 검사를 통과했습니다. DRC는 0건이고 LVS는 일치했습니다. LVS 상세 결과에는 웰·기판 탭 관련 경고 2건이 남았습니다.
- 참가자는 이 대화에서 사전 검증 수치를 볼 수 있었습니다. 이 회차에서는 첫 단계의 발견 가능성과 안내 후의 작업 흐름을 관찰했습니다.

| 우선순위 | 관찰 근거 | 개선 후 확인할 행동 |
| --- | --- | --- |
| 완료를 막음 | 처음 시작할 행동이 분명하지 않아 단계별 안내를 요청했고, 영어 메뉴에서 항목을 찾기 어려웠다고 보고했습니다. | 시작 화면에서 화면 언어를 선택하고 시험용 프로젝트를 도움 없이 엽니다. |
| 도움 필요 | UGF를 두 배로 계산한 뒤 입력할 곳을 다시 물었습니다. | 파생 창의 `ugf` 행에서 주파수 단위와 하한 칸의 의미를 이해하고 목표를 입력합니다. |
| 도움 필요 | 파생을 마친 상태에서 프로젝트가 저장되지 않았습니다. | 파생 결과에서 저장할 수 있는 위치를 찾아 저장을 완료하고 새 셀을 다시 엽니다. |
