# 단축키

Windows와 Linux의 `Ctrl`은 macOS에서 `Cmd`입니다. 앱은 실행 중인 플랫폼에 맞게 단축키를 표시합니다
(Windows와 Linux에서는 `Ctrl+K`, macOS에서는 `⌘K`). 메뉴, 툴팁, 이 목록 모두 마찬가지입니다. 앱에서
`F1`을 누르면 이 목록이 표시됩니다.
캔버스 키는 마우스가 캔버스 위에 있고 텍스트 필드에 포커스가 없을 때 동작합니다.

## 일반

| 키 | 동작 |
|---|---|
| `Ctrl+K`, `Ctrl+Shift+P` | 명령 팔레트 |
| `Ctrl+S`, `F2` / `Ctrl+Shift+S` | 저장 / 다른 이름으로 저장 |
| `Ctrl+O` | 프로젝트 열기 |
| `Ctrl+N` | 새 셀 |
| `Ctrl+W` | 탭 닫기 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Shift+Z`, `Ctrl+Y` | 다시 실행 |
| `Ctrl+1` ... `Ctrl+4` | Home, Schematic, Simulation, Layout 워크스페이스 |
| `F5`, `Ctrl+Enter` | 시뮬레이션 실행 |
| `Ctrl+J` | 콘솔 표시 전환 (레이아웃 편집기에서는 `Ctrl+J`가 좌우 반전) |
| `Ctrl+,` | 설정 |
| `F1` | 단축키 |

## 캔버스 (회로도와 레이아웃)

| 키 | 동작 |
|---|---|
| 휠 | 위 / 아래로 이동 (Conventional 프로필: 커서 위치에서 확대·축소) |
| `Ctrl`+휠, 핀치 | 커서 위치에서 확대·축소 |
| `Shift`+휠 | 가로로 이동 |
| 가운데 버튼 드래그 | 이동 |
| 오른쪽 드래그 | 레이아웃: 상자 영역으로 확대 (Conventional 프로필: 이동), 회로도: 이동 |
| `F` | 창에 맞추기 |
| `Esc` | 현재 작업 취소, 다음엔 Select로 복귀, 그다음 선택 해제 |
| `Del`, `Backspace` | 선택 항목 삭제 |
| `Ctrl+A` | 모두 선택 |
| `Ctrl+D` | 선택 항목 복제 (레이아웃: 모두 선택 해제) |
| `Shift`/`Ctrl`+클릭 | 선택에 추가 또는 선택에서 제거 |

마우스 동작은 **Settings**(`Ctrl+,`)의 **Interaction** 프로필을 따릅니다. **Virtuoso**(기본값)는
Virtuoso 기본 동작과 같아서 휠로 이동하고, `Ctrl`+휠로 마우스 위치에서 확대·축소하며, 오른쪽 드래그로
상자 영역을 확대합니다. **Conventional**은 휠로 확대·축소하고 오른쪽 드래그로 이동합니다. 바인드키는
두 프로필에서 같습니다.

## 회로도

| 키 | 동작 |
|---|---|
| `W` | 와이어 |
| `T` | 넷 레이블 |
| `R` `C` `L` | 저항, 커패시터, 인덕터 |
| `V` `I` | 전압원, 전류원 |
| `D` | 다이오드 |
| `N` `P` | NMOS, PMOS |
| `G` `S` | 접지, 전원 |
| `Space` / `X` | 회전 / 미러 (배치 중이거나 선택 항목) |
| `/` | 와이어 꺾임 방향 전환 |

## 레이아웃

레이아웃 키는 Cadence Virtuoso (IC6) 기본 바인드키를 따릅니다.

| 키 | 동작 |
|---|---|
| `Esc` | 대기 중인 점 취소, 부분 선택 해제, 그다음 Select로 복귀 |
| `S` | Stretch: 모서리나 꼭짓점을 클릭한 뒤 목적지 클릭, 또는 모서리 위로 상자를 드래그(또는 부분 선택 사용)한 뒤 기준점과 목적지 클릭 |
| `F4` | 부분 선택 전환 (모서리와 꼭짓점 선택) |
| `M` / `C` | 이동 / 복사: 기준점을 클릭한 뒤 목적지 클릭 (복사는 반복) |
| 오른쪽 클릭 / `Shift`+오른쪽 클릭 | 이동이나 복사 중: 90° 회전 / 좌우 반전 |
| 가운데 클릭, 오른쪽 클릭 | 팝업 메뉴 (오른쪽 클릭은 대기 중인 명령 점이 없을 때만) |
| 오른쪽 드래그 | 상자 영역으로 확대 |
| `q` | Edit Object Properties 폼 |
| `F3` | 현재 명령의 Options 폼 |
| `e` / `Shift+E` | Display Options / Layout Editor Options 폼 |
| `R` | 사각형 (드래그 또는 두 번 클릭) |
| `Shift+P` / `P` | 폴리곤 / 패스 |
| `L` / `O` / `I` / `K` | 레이블 / 비아 / 인스턴스 / 자 |
| `Shift+C` / `Shift+M` / `Shift+S` | 잘라내기(chop) / 병합 / 나누기(split) |
| `Shift+O` | 선택 항목(또는 이동 중인 항목)을 90° 회전 |
| 패스를 그리는 중 `+` / `-` | 비아를 놓고 위 / 아래 메탈에서 계속 |
| `u` / `Shift+U` | 실행 취소 / 다시 실행 (`Ctrl+Z` / `Ctrl+Y`도 동작) |
| `y` / `Shift+Y` | 복사(yank) / 붙여넣기 (`Ctrl+C` / `Ctrl+X` / `Ctrl+V`도 동작) |
| `T` | 레이어 탭: 커서 아래 레이어를 활성 레이어로 지정 |
| `G` | 그래비티 스냅 전환 |
| `Ctrl+A` / `Ctrl+D` | 모두 선택 / 모두 선택 해제 |
| `Shift+X` / `x` / `Shift+B` | 커서 아래 인스턴스로 들어가기 / 제자리에서 편집 / 돌아오기 |
| `Shift+T` | 계층 트리 |
| `Ctrl+J` | 좌우 반전 (이동이나 복사 중에도) |
| `Shift+N` | 넷 표시 모드 (**Extract** 후 도형을 클릭하면 해당 넷 강조) |
| `Ctrl+.` | 빠른 수정: DRC 위반의 수정 후보 ([검증](verification.md) 참고) |
| `Enter` | 패스나 폴리곤 완료 |
| `Backspace` | 그리는 중 마지막 점 제거 |
| `Shift`+클릭 | 임의 각도 폴리곤 점 |
| 화살표 키 | 이동 |
| `Shift`+화살표 키 | 선택 항목을 스냅 10단계만큼 미세 이동 |
| `Z` / `Shift+Z` | 상자 확대 / 축소 |
| `[` / `]` | 커서 위치에서 확대 / 축소 |
| `W` / `Shift+W` | 이전 / 다음 뷰 |
| `F` | 화면에 맞추기 |
| `Shift+K` | 모든 자 지우기 |
| `Shift+F` / `Ctrl+F` | 모든 계층 / 최상위만 |
| `0` ... `8`, `9` | 표시할 계층 깊이 (`9` = 전체) |
| 같은 지점 다시 클릭 | 겹친 항목을 차례로 선택 |
| 오른쪽에서 왼쪽으로 상자 | 상자에 닿는 모든 것 선택 (왼쪽에서 오른쪽: 완전히 포함된 것만) |
| 인스턴스 더블클릭 | 해당 셀 열기 |

`Ctrl+Z`는 애플리케이션의 다른 부분과 마찬가지로 실행 취소입니다(Virtuoso에서는 확대에 할당됨).

## 시뮬레이션 플롯

스크롤로 확대·축소하고, 드래그로 이동하며, 더블클릭으로 보기를 초기화합니다. 트레이스 위에 마우스를
올리면 값을 읽을 수 있습니다.
